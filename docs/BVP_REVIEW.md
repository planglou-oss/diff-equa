# ผลตรวจคำอธิบาย Boundary-Value Problems

เพิ่มคำอธิบาย AI ครบ **25/25 ข้อ** (1998–2026) รวมทุกข้อย่อย ตรวจภาพโจทย์และภาพเฉลยครบ แล้วตรวจด้วย SymPy ผ่าน **293/293 รายการ** และ KaTeX แบบ strict **392 สูตร** เป็นการตรวจด้วย AI ไม่ใช่การรับรองจากอาจารย์

สถานะ: **23 ai_checked + 2 needs_clarification** (ข้อ 15 และ 22)

## สิ่งที่แก้และข้อจำกัดของโจทย์

| ข้อ | ผลตรวจ |
|---|---|
| 14 | ภาพเฉลยเขียนสัมประสิทธิ์ sin(x) sin(2t) เป็น -1/4 ค่าที่ผ่านความเร็วเริ่มต้นคือ +5/4 |
| 15 | ความถี่ที่ถูกคือ 2 omega_n² และต้องมี c/(2 omega_n²) คูณพจน์ไซน์เพื่อให้ initial velocity ศูนย์ ข้อมูล f=x(1-x) ยังมี f'(0)=1 และ f''(1)=-2 ไม่ตรงขอบเขตแบบอนุพันธ์ จึงแสดง generalized L² solution พร้อมป้ายสอบถามผู้สอน หากต้องการ classical solution |
| 18 | แยกค่าเฉลี่ย a0=integral(f)=2/pi ออกจากสัมประสิทธิ์ an=2 integral(f cos(n pi x)) สำหรับ n>=1; ภาพเฉลยเดิมทำให้โหมดคงที่ผิดเป็น 4/pi ทั้งสี่ข้อย่อย |
| 22 | ระบบ Dirichlet–Neumann ความยาว 1/2 อนุญาตความถี่ (2n-1) pi ทำให้ trace ที่ปลายต้องเปลี่ยนเครื่องหมายเมื่อ t เพิ่ม 1 แต่ cos(2 pi t) มีค่าเดิม จึงไม่มีคำตอบที่ผ่านข้อมูลทุกตัวสำหรับทุกเวลา แสดงกรณีเปลี่ยนเป็น cos(pi t) เป็นตัวอย่างโดยติดป้ายว่าต้องแก้ข้อมูลก่อน |

## การตีความอนุกรมและมุมเริ่มต้น

- ข้อ 2 เปลี่ยนอุณหภูมิปลายซ้ายทันทีตามโจทย์: รักษาขอบเขตสำหรับ t>0 และคืน initial temperature ในช่วงเปิด
- ข้อ 3 เป็น modal/energy beam solution; ไม่อ้างว่าสามารถหาอนุพันธ์อันดับสูงของอนุกรมที่ t=0 ได้ทุกจุด
- ข้อ 15 ข้อมูลเริ่มต้นไม่อยู่ใน energy form domain ที่บังคับ slope ที่ปลาย จึงให้เพียง generalized L² interpretation และตั้ง needs_clarification
- ข้อ 17 มี initial values ที่ปลายต่างจากขอบเขตศูนย์ สูตรให้ heat solution สำหรับ t>0 และคืนข้อมูลในช่วงเปิด/L² แต่ไม่ต่อเนื่องที่มุมเริ่มต้นตามข้อมูลทุกจุด
- ข้อ 18 initial derivatives ไม่ตรงฉนวนที่ปลายหนึ่ง; อนุกรม heat equation คืนอุณหภูมิเริ่มต้นและใช้ขอบเขตอนุพันธ์สำหรับ t>0 ไม่มีการอ้างความต่อเนื่องของอนุพันธ์ที่มุมเริ่มต้น

## ทำซ้ำ

```powershell
python scripts/verify_bvp.py
```

ต้องมี SymPy เฉพาะในเครื่องพัฒนา โค้ดตรวจ PDE ของโหมด ขอบเขต initial modal values สัมประสิทธิ์จากอินทิกรัล exact และพยานแสดงความขัดแย้ง การตรวจอนุกรมใช้ eigenmodes และ coefficients ไม่อ้างว่าผลรวมจำนวนจำกัดแทน initial function ได้ตรงทุกจุด

ดูรายการตรวจและ SHA-256 ของเนื้อหา ภาพโจทย์ ภาพเฉลย และสคริปต์ใน [bvp-review.json](bvp-review.json) สคริปต์ใช้สูตรที่ถอดจากภาพ ไม่ได้ parse สมการทั้งหมดจาก HTML อัตโนมัติ
