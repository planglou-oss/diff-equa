# ผลตรวจคำอธิบาย Z-transform

ทำคำอธิบาย AI ครบ **27/27 ข้อ** (1997–2026) รวมทุกข้อย่อย ตรวจภาพโจทย์และภาพเฉลยต้นฉบับทุกข้อ แล้วคำนวณซ้ำด้วย SymPy ผ่าน **422/422 รายการ** สถานะ `ai_checked` ทั้ง 27 ข้อ ไม่ใช่การรับรองจากอาจารย์

## เนื้อหาและขอบเขต

- อธิบายการแปลงตรง/กลับ การแยกเศษส่วน การเลื่อนดัชนี สมการผลต่างและระบบสมการ พร้อมค่าเริ่มต้นและวิธีตรวจกลับ
- ใช้นิยามด้านเดียวตั้งแต่ n=0 และระบุ ROC โดยคงคำตอบทั่วไปเมื่อโจทย์ไม่ให้ค่าเริ่มต้น
- ข้อ 4: ระบุกรณี sin(lambda)=0 ด้วยลิมิต และเมื่อ cos(lambda)=0 ค่า A ไม่เอกฐาน แม้เลือก A=-2 ได้เสมอ
- ข้อ 7: แยกคำตอบลำดับ ณ จุดสุ่ม ออกจากฟังก์ชันระหว่างจุดสุ่มซึ่งไม่ได้ถูกกำหนดเอกฐานด้วยข้อมูลสองจุด
- ข้อ 11 และ 13: คงพจน์เดลตาที่ n=0,1 พร้อมเฉลยเต็ม แม้เฉลยภาพข้อ 13 อ้างไปข้อเก่า
- ข้อ 20: ใช้ค่า y[-1]=0 จากโจทย์เมื่อตรวจสมการที่ n=0 ไม่ขยายสูตรสำหรับ n>=0 ย้อนหลังโดยไม่มีเหตุผล
- ข้อ 23,25,26: คงค่าคงที่อิสระสี่ตัว เพราะโจทย์ไม่ระบุค่าเริ่มต้น

## ทำซ้ำ

ต้องมี Python และ SymPy ในเครื่องพัฒนา (ไม่มีผลต่อ runtime ของ Go):

```powershell
python scripts/verify_z_transform.py
```

สคริปต์ตรวจสมการเชิงสัญลักษณ์ ค่าเริ่มต้น เอกลักษณ์ของฟังก์ชันตรรกยะ อินทิกรัล Chebyshev และสัมประสิทธิ์ Laurent แบบ exact การตรวจสัมประสิทธิ์ตรวจเฉพาะจำนวนพจน์ที่ระบุ ไม่ใช่หลักฐานเพียงอย่างเดียวของทั้งอนุกรม รายการตรวจและ hash ของเนื้อหา/ภาพอยู่ใน [z-transform-review.json](z-transform-review.json) ตัวสคริปต์ใช้สมการที่ถอดจากภาพ ไม่ได้ parse สูตรทั้งหมดใน HTML โดยอัตโนมัติ
