EE Math I - แพ็กเกจ Windows x64

วิธีเปิด
1. แตก ZIP ทั้งหมดไปยังโฟลเดอร์ที่เขียนไฟล์ได้ เช่น Desktop หรือ Documents
2. ดับเบิลคลิก START.bat (ไม่ต้องติดตั้ง Node.js หรือ Go)
3. รอการนำเข้ารูปโจทย์ครั้งแรก เบราว์เซอร์จะเปิดเองที่ http://127.0.0.1:8080
4. เปิดหน้าต่างโปรแกรมค้างไว้ระหว่างใช้งาน กด Ctrl+C ในหน้าต่างนี้เพื่อหยุด

หากเบราว์เซอร์ไม่เปิด ให้เปิดที่อยู่ด้านบนเอง
หากพอร์ต 8080 ถูกใช้อยู่ ให้ปิดหน้าต่างโปรแกรมเก่า หรือเปิด Terminal ในโฟลเดอร์นี้แล้วรัน:
.\START.bat -Port 8081
จากนั้นใช้ http://127.0.0.1:8081 (ข้อมูล localStorage ของแต่ละพอร์ตแยกกัน)

ใช้งานโดยไม่ใส่ API key ได้
ดูโจทย์ รูปเฉลย คำอธิบาย AI ที่บันทึกไว้ ฝึกข้อสอบ และตรวจตัวเลือกที่เตรียมไว้ได้
เฉลย Laplace, Z-transform และ Boundary-Value Problems รุ่นล่าสุดรวมมากับ executable แล้ว
เฉพาะ AI chatbot แบบถามตอบสดเท่านั้นที่ต้องใช้อินเทอร์เน็ตและ Gemini API key ของผู้ใช้เอง
หากต้องการเปิด chatbot ให้คัดลอก .env.example เป็น .env ตั้ง GEMINI_API_KEY และ GEMINI_MODEL แล้วเปิดใหม่
แพ็กเกจนี้ไม่รวม API key หรือประวัติแชต/ฐานข้อมูลส่วนตัวของผู้สร้าง

ไฟล์และข้อมูล
- EE-Math.exe: Go server ที่ build แล้ว (ถ้าเปิดโดยตรง ต้องเปิดเบราว์เซอร์เอง)
- frontend/dist/: หน้าเว็บและฟอนต์ที่ build แล้ว ใช้งานผ่าน server ไม่ใช่ดับเบิลคลิก index.html
- exam201_solutions.html: ข้อมูลต้นทางสำหรับนำเข้าครั้งแรก
- data/: สร้างอัตโนมัติเมื่อเริ่มใช้ เก็บฐานข้อมูล ภาพ และประวัติแชต/รายงาน
- ความคืบหน้า รายการโปรด โน้ต และชุดฝึกเก็บในเบราว์เซอร์เครื่องนั้น ไม่ sync ข้ามเครื่อง

เก็บไฟล์ทั้งหมดในโฟลเดอร์เดียวกัน อย่าส่งเฉพาะ EE-Math.exe หรือ START.bat
การล้างข้อมูลเว็บไซต์หรือเปลี่ยน browser/port จะทำให้เห็นข้อมูลการเรียนคนละชุด
ต้องมี Windows x64 และเบราว์เซอร์ ไม่ต้องใช้สิทธิ์ Administrator
